Decoding shopping decorators

Microsoft Framework Psychology Visual Design

Overview

Designed a detailed framework for creating and scaling decorators across Microsoft Shopping teams. Decorators are visual elements — badges, labels, urgency cues — that influence purchase decisions. I also built the north star vision for the decorator system.

Impact

Created a shared vocabulary across teams and achieved instant user engagement.

My Role

Owned the research, framework design, and visual system creation. Partnered with multiple shopping teams to ensure the framework was adoptable and consistent across surfaces.

Key Design Decisions

  • Mapped decorator types to psychological principles — urgency, social proof, scarcity, and savings perception
  • Created a categorization system spanning emotional, real-world, physical, and seasonal decorators
  • Built a modular component library that teams could adopt independently
  • Designed comparative and celebratory decorator patterns for different shopping contexts
